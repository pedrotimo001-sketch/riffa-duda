# Rifa Baby Mirella ou Henry

PWA estatica mobile-first hospedada no GitHub Pages.

## Recursos

- 100 numeros de rifa.
- Cadastro de nome, telefone, observacao e status.
- Status: Livre, Reservado e Pago.
- Salvamento persistente no aparelho via `localStorage`.
- Busca por numero, nome, telefone, status ou observacao.
- Painel de arrecadacao com valor por numero.
- Backup em JSON, importacao de backup e exportacao CSV.
- Manifest e service worker para uso como PWA no iPhone.

## Endereco publicado

https://pedrotimo001-sketch.github.io/riffa-duda/

## Observacao importante

O GitHub Pages hospeda arquivos estaticos. Sem banco de dados, os dados ficam salvos no navegador/aparelho usado. Use o backup JSON com frequencia antes de trocar de celular, limpar navegador ou compartilhar a gestao com outra pessoa.
